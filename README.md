# slotbeacon

Live Solana mainnet as a **coastal lighthouse**.

The Fresnel beam sweeps with the slot clock. Ships on the horizon are recent txs — lantern color by program family. Fog thickness / lens heat ≈ fee pressure. Wrecked hulks and snuffed lanterns ≈ failed txs. Close the shutter to freeze a sample.

Not an explorer. Not a dashboard. Not a newspaper.
